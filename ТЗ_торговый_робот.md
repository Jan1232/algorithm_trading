# Техническое задание: торговый робот

Извлечено из практической части книги Ю. Чеботарёва «Торговые роботы на российском фондовом рынке» (главы 7, 8, 10). Только инженерная часть: архитектура, правила, формулы, ограничения. Без обоснования стратегии и философии рынка.

---

## 1. Инженерные принципы (базовые допущения архитектуры)

1. Рынок трактуется как **случайная нестационарная последовательность цен**. Робот **не прогнозирует** и не ищет тренды — он реагирует на последний бар и управляет рисками. Все модули строятся под это допущение.
2. Управлять можно **только рисками**, не ценой. Риск = максимальная просадка депозита, заданная инвестором заранее.
3. **Никакой оптимизации параметров по историческим данным.** Оптимизированные параметры устойчивы только на коротком участке и требуют постоянной переоптимизации → архитектурный запрет. Целевая система — **безпараметрическая** (см. §5).
4. Нейросети под запретом для генерации сигналов: почти мгновенно уходят в переобучение на нестационарном ряде. (Прим.: это ограничение относится к торговой логике, не к инфраструктуре.)
5. Алгоритм должен быть **открытым и детерминированным** («не чёрный ящик»): каждое решение воспроизводимо из входных данных.
6. Единица данных — **тик** (сделка купли/продажи). Из тиков на интервале `dt` собирается бар: `open`, `high`, `low`, `close`. Интервал бара произвольный (не обязательно кратный минуте) — тиковая природа это допускает.

---

## 2. Жёсткие требования к торговой системе (условия из «плана создания робота»)

- Уровень **Stop-loss определяется ДО входа в позицию.**
- Уровни Stop-loss и Take-profit должны вычисляться просто и однозначно из данных бара, без субъективных факторов (размер счёта, настроение, чужое мнение — исключены по определению, т.к. робот).
- Выбранная торговая логика **не корректируется во время торговой сессии.** Пересмотр — только вне сессии.
- Обязательный **режим виртуальной торговли (paper trading)** до боевого запуска.
- Запрет на отключение торговой логики в процессе реальных операций (никаких ручных вмешательств в открытые правила).

Требования к самой системе:
- универсальность: работает на бычьем, медвежьем и боковом тренде;
- простая, ясная торговая идея;
- суммарная доходность прибыльных сделок существенно превышает убыточные;
- устойчивость к изменению параметров (в идеале — их отсутствие);
- доходность не хуже пассивного вложения в биржевой индекс;
- система не должна быть единственно возможной (заменяемость модулей).

## 3. Управление ордерами (практика исполнения)

Из примера «пробойной системы». Робот работает **на закрытии сформировавшегося бара**, решение принимается по последнему бару, а не по всей истории.

**Восходящий тренд (только длинные позиции):**
- Вход: `stop-limit order` на пробое максимума предыдущего бара.
- Удержание: после формирования нового бара сверять `close` текущего с `close` предыдущего. Если `close` растёт — держать. Как только `close` ниже предыдущего — закрыть всё по `close market order`.

**Нисходящий тренд (только короткие позиции):**
- Вход: `sell short stop-limit order` на пробое минимума предыдущего бара.
- Удержание: держать, пока `close` падает. Как только `close` выше предыдущего — закрыть по `buy covered market order`.

**Скользящий Stop-loss («первый эшелон защиты депозита»):**
- На восходящем тренде: стоп выставляется на **минимуме предыдущего бара**. Цена ушла ниже `low` предыдущего бара → закрыть всё по рынку.
- На нисходящем тренде: стоп на **максимуме предыдущего бара**. Цена выше `high` предыдущего бара → закрыть по рынку.
- Может давать как плюс, так и минус — это нормально.

**Прибыль/убыток сделки:** `s = p_sell − p_buy` (для шорта: `s = p_sell_short − p_buy_covered`).

**Скальпинг (если нужен HFT-режим) — алгоритм из §7.5:**
1. следить за «поводырями» (например тиковые изменения фьючерса E-mini S&P-500, нефть Brent, EUR/USD);
2. прогноз на 2–3 сек, как поводырь отразится на рабочем инструменте;
3. вход в сторону прогноза;
4. ждать отработки;
5. фиксация прибыли (5–10 пунктов, много сделок).
   - **Обязательная коррекция на ошибочный прогноз:** как только реальность разошлась с прогнозом (причина не важна) — немедленный выход наиболее быстрым способом.
   - Среднее время в позиции < 20 сек. Депозит соизмерим с гарантийным обеспечением (маржой).

## 4. Критический риск-контроль для HFT (обязательно)

При частоте порядка **1000 заявок/сек** сбой без контроля за 2 минуты = ~120 000 ошибочных заявок. Требуется:
- **абсолютный автоматический контроль** количества и корректности исходящих заявок;
- **kill-switch**: аварийный останов, срабатывающий за секунды, а не минуты;
- лимиты на частоту, объём и суммарную экспозицию заявок.

## 5. Безпараметрическая торговая система (целевая реализация из §10.24)

Это рекомендуемое ядро. Решение по цене закрытия последнего сформировавшегося бара.

Обозначения бара `i`: `O` (open), `C` (close), `H` (high), `L` (low).

**Правило 1 — вход в длинную позицию** (все три условия):
```
H_i > H_{i-1}
L_i > L_{i-1}
(H_i + L_i)/2 > L_i + Δ
```

**Правило 2 — вход в короткую позицию** (все три условия):
```
L_i < L_{i-1}
H_i < H_{i-1}
(H_i + L_i)/2 < H_i − Δ
```

**Правило 3:** если ни Правило 1, ни Правило 2 не выполнены — выйти из рынка / оставаться вне рынка.

**Ключевой приём — Δ вычисляется из самого бара, без оптимизации:**

Коэффициент `k` (диапазон 0…1):
```
длинные:  k = (C_i − O_i) / (H_i − L_i)
короткие: k = (O_i − C_i) / (H_i − L_i)
```
- `k = 0` → типичный боковой бар → Δ большая → вход не выполняется;
- `k = 1` → импульсный трендовый бар → Δ → 0.

Формула:
```
Δ = (H_i − L_i) * (1 − k)
```
Δ считается индивидуально для каждого бара. Оптимизация по истории не нужна.

Недостаток метода — просадки на отдельных участках. Снижаются диверсификацией по времени (§6).

## 6. Диверсификация по времени (тайм-фреймы) — снижение просадки

Один актив рассматривается одновременно в разных масштабах времени. Каждый тайм-фрейм — независимый случайный процесс со своей кривой доходности; связи между величиной тайм-фрейма и просадкой нет.

**«Нарезка» тайм-фреймов (пример под сессию ММВБ 495 мин, 10:30–18:45):**
- шаг 15 мин → 33 тайм-фрейма: 15, 30, 45, …, 495 мин.
- в каждом тайм-фрейме крутится своя копия торговой логики независимо.

**Определение направления рынка через голосование тайм-фреймов:**
- `N` = общее число тайм-фреймов = `N⁺ + N⁻ + N⁰`
  (сигналы на лонг / шорт / нет сигнала).
- `N⁺ > N⁻` → начало восходящего тренда;
- `N⁺ > N⁻ + N⁰` → уверенное преобладание лонгов.
- Направление рынка = какой группы тайм-фреймов больше.

**Распределение депозита `D` (на примере лонгов):**
1. найти `N⁺` тайм-фреймов с сигналом на лонг;
2. из них отобрать `N_R⁺` — те, где **просадка доходности меньше риска `R`**;
3. равномерно распределить: каждому по `D / N_R⁺`.

**Отсечение по риску:** если на каком-то тайм-фрейме просадка превысила `R` — временно **не вкладывать** средства в этот тайм-фрейм (пропустить его), пока не восстановится.

Общий профит по всем активам `i` и тайм-фреймам `j`:
```
Profit = Σ_i Σ_j (p_sell[i,j] − p_buy[i,j])
```

## 7. «Второй эшелон защиты депозита» (глобальный лимит просадки)

Поверх скользящих стопов. Перед открытием любой новой позиции проверяется суммарный потенциальный убыток по скользящим стопам всех открытых позиций:

```
Σ_i Σ_j (Low[i,j,k-1] − p_buy[i,j])           (по лонгам)
  + Σ_i Σ_j (p_sell_short[i,j] − High[i,j,k-1])   (по шортам)
  ≥ −P
```
где `k` — формирующийся бар, `k-1` — предыдущий, `P` — допустимая инвестором просадка депозита `D`.

- Условие выполняется → разрешить открытие новых позиций.
- Не выполняется → **новые позиции не открываются**, даже если на депозите есть свободные средства.

Смысл: при форс-мажорном развороте сработает первый эшелон (скользящие стопы), а второй эшелон гарантирует, что суммарные потери не выйдут за заданный инвестором риск.

## 8. Оценка устойчивости системы (валидация, а не бэктест доходности)

- **Доходность прошлого НЕ является критерием** устойчивости.
- Устойчивый параметр = **плотность распределения** `g` случайной величины `s = p_sell − p_buy`, не зависящая от времени.
- Критерий прибыльности системы (площади под плотностью распределения):
```
∫_{−∞}^{0} g·ds  <  ∫_{0}^{+∞} g·ds
```
т.е. масса положительных исходов должна перевешивать отрицательные.
- Проверять и на одном активе, и на портфеле. Положительное матожидание при большом числе сделок `n` и глубокой диверсификации даёт положительную тенденцию накопления.

**Матожидание сделки (главный контрольный показатель):**
```
Mo = P(выигрыш) * средний_выигрыш − P(проигрыш) * средний_проигрыш
```
- Не путать высокую вероятность выигрыша с положительным Mo: методы с высокой P(win) часто имеют **отрицательное Mo** → разорение.
- Целевой принцип money management: **быстро резать убытки, давать прибыли расти.**

## 9. Портфель и параметры промышленного примера (ориентир)

- Торговый робот управлял портфелем из 16 эмитентов (голубые фишки: Газпром, ЛУКойл, ГМК Норникель, Ростелеком, Татнефть, Сургутнефтегаз, Мосэнерго, Северсталь, УралСвязьИнвест, Газпромнефть и др.), заданный риск ≤ 10%.
- За 9 месяцев просадка не превысила 10%, тогда как индекс РТС в тот же период падал более чем на 50%.
- Глубокая диверсификация по множеству активов — обязательна для крупного капитала: сначала сохранение капитала, потом приумножение. Цель — «зарабатывать не много, а постоянно, с контролируемым риском».
- На российском рынке ~10 голубых фишек (против 500+ на US), поэтому **диверсификация по времени критична** — она компенсирует малое число ликвидных активов.

---

## 10. Ликвидность актива (фильтр для отбора инструментов)

По числу тиков за `dt`:
- > 1 сделки за 1 сек → сверхликвидный, «голубая фишка»;
- 1–10 сделок за 1 день → неликвидный, 2–3 эшелон (исключать или отдельная обработка).
