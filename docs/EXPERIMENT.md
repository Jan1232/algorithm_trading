# Протокол эксперимента (заморозка политики)

## Правила
1. При первом запуске создаётся `data/experiment.json` с `policy_hash`.
2. Любое изменение P, R, символов, TF, издержек, exit_mode → новый hash → старый эксперимент недействителен.
3. Окно A: проверка, что система торгует и предохранители живы (не судить о edge).
4. Окно B: смотреть Mo один раз после издержек; без подкрутки конфига.

## Критерии прохождения (по умолчанию в experiment.json)
- min_closed_trades >= 200
- Mo > 0 после fees/slippage/funding
- >= 70% TF-корзин с положительным Mo
- maxDD <= P
- доля блокировок echelon2 в [1%, 50%]

## Команды
```bash
python -m bot --report
python -m bot --promote-b
```
